# Orientation

Welcome to Programming for Information Systems. The course teaches Python through a fictional campus food-rescue coordination system.

1. Read the [course overview](COURSE_OVERVIEW.md) and meet [the instructor](INSTRUCTOR.md).
2. Open the [Orientation PDF](/slides/Orientation.pdf) for the course workflow, learning expectations and proposed assessment.
3. Follow [Setup](SETUP.md): open your weekly notebook in Colab, save a personal copy and connect to Python. GitHub access is not needed for these public notebooks.
4. Start [Week 1](learning_materials/Week_01.ipynb) using [Open Week 1 in Colab](https://colab.research.google.com/github/loem-ms/programming-for-information-systems-site/blob/main/content/downloads/Week_01.ipynb). The [offline ZIP](/downloads/Week_01.zip) is optional.
