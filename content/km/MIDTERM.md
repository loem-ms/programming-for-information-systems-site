## ចូលទៅកាន់ការប្រឡង (ត្រូវការលេខកូដ PIN)

Notebook សម្រាប់ midterm ត្រូវបានចាក់សោ រហូតដល់ពេលប្រឡងចាប់ផ្ដើម។ គ្រូនឹងប្រកាស **លេខកូដ PIN** នៅក្នុងថ្នាក់។

- **[🔒 បើកទំព័រប្រឡង Midterm (ត្រូវការលេខកូដ PIN)](/exam/km/midterm.html)** — បញ្ចូល PIN ដែលគ្រូផ្ដល់ ដើម្បីទាញយក `Midterm.ipynb` ហើយបើកវានៅក្នុង Google Colab។
- **[📄 ស្លាយណែនាំ Midterm (PDF)](/slides/km/Midterm_Brief.pdf)** — ទម្រង់ ច្បាប់ និងរបៀបត្រៀមខ្លួន (បង្ហាញនៅសប្ដាហ៍ទី 4 វគ្គទី 2)។

> **គន្លឹះ៖** មុនពេលប្រឡង សូមប្រាកដថាអ្នកបានចូលគណនី Google រួចរាល់ ដើម្បីឱ្យ [Google Colab](https://colab.research.google.com/) បើកបានភ្លាមៗ បន្ទាប់ពីអ្នកទាញយក `Midterm.ipynb`។

## អ្វីដែល midterm ពិនិត្យ

Midterm នេះពិនិត្យ **ការយល់ដឹង** របស់អ្នកពីសប្ដាហ៍ទី 1–4 នៅក្នុងបរិបទប្រចាំថ្ងៃថ្មីមួយ (មិនមែនការទន្ទេញ syntax ទេ)៖

| ផ្នែក | កិច្ចការ | ពេលវេលាស្នើ | ពិន្ទុ |
|---|---|---:|---:|
| 1 | អាន និងតាមដានកូដដោយដៃ (type, loop trace, records) | 12 នាទី | 24 |
| 2 | បំប្លែង flowchart (គំនូសតាងលំហូរ) ទៅជា function វិធាន + ពន្យល់ការផ្លាស់ប្ដូរវិធាន | 15 នាទី | 24 |
| 3 | ធ្វើការជាមួយ list នៃ records ហើយ return dictionary សេចក្ដីសង្ខេប | 18 នាទី | 28 |
| 4 | ត្រួតពិនិត្យ តេស្ត និងកែសម្រួលកូដ AI + របាយការណ៍ផលប៉ះពាល់ | 15 នាទី | 24 |
| ចុងបញ្ចប់ | **បន្ទាត់កូដសំខាន់របស់ខ្ញុំ (My key line)** (ចាំបាច់ត្រូវបំពេញ) + clean run | 1 នាទី | ចាំបាច់ |

**ផ្នែកនីមួយៗដាច់ដោយឡែកពីគ្នា។** បើអ្នកជាប់គាំងនៅផ្នែកណាមួយ សូមរំលងទៅផ្នែកបន្ទាប់សិន រួចត្រឡប់មកវិញ។

## កាលវិភាគវគ្គប្រឡង (សរុប 90 នាទី)

1. **0–5 នាទី · ការរៀបចំ៖** បញ្ចូលលេខកូដ PIN ដែលគ្រូប្រកាសក្នុងថ្នាក់ ទាញយក `Midterm.ipynb` upload ទៅ Google Colab រួច run cell **Setup**។
2. **5–65 នាទី · ការប្រឡងម្នាក់ឯង (60 នាទី)៖** ធ្វើផ្នែកទី 1–4 និង **បន្ទាត់កូដសំខាន់របស់ខ្ញុំ (My key line)** ដោយស្ងៀមស្ងាត់។
3. **65–72 នាទី · Clean run និងដាក់ស្នើ៖** ចុច **Runtime → Restart session and run all** ពិនិត្យគ្រប់ចម្លើយ រួចដាក់ស្នើ file `.ipynb` តាមការប្រកាស។
4. **72–90 នាទី · ពិភាក្សាចម្លើយផ្ទាល់៖** ពិនិត្យអន្ទាក់សំខាន់ៗរួមគ្នា និងចាប់ផ្ដើមការពិនិត្យផ្ទាល់មាត់ខ្លីរយៈពេល 2–3 នាទី។
