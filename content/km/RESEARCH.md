កិច្ចការខ្លីៗចំនួនប្រាំមួយ **5% ក្នុងមួយកិច្ចការ** (សរុប 30%)។ កិច្ចការនីមួយៗយកគំនិតរបស់សប្ដាហ៍មួយ ចេញពី notebook ទៅមើលក្នុងប្រព័ន្ធពិតមួយដែលអ្នកស្គាល់។ សរសេរប្រហែលកន្លះទំព័រ ជាពាក្យសម្ដីផ្ទាល់ខ្លួនរបស់អ្នក ដោយមានប្រភពយ៉ាងហោចណាស់មួយ ដែលបញ្ជាក់ឈ្មោះច្បាស់។

## R1 · ប្រព័ន្ធព័ត៌មានពិតមួយ

ជ្រើសរើសប្រព័ន្ធមួយដែលអ្នកធ្លាប់ប្រើ: ការចុះឈ្មោះចូលរៀន app ឡានក្រុង ឬ app ទិញសំបុត្រ បណ្ណាល័យ ជួររង់ចាំនៅមន្ទីរពេទ្យ app ផ្ទេរប្រាក់តាមទូរស័ព្ទ (mobile money)។ នរណាប្រើវា (យ៉ាងហោចណាស់តួនាទីពីរ)? វារក្សាទុកទិន្នន័យអ្វីខ្លះ? ប្រាប់វិធានមួយដែលវាអនុវត្តតាម និងរឿងមួយដែលអាចខុស ព្រមទាំងនរណាដែលនឹងរងផលប៉ះពាល់។

## R2 · វិធាន និង edge case

ជ្រើសរើសវិធានមួយពីជីវិតពិត: ថ្លៃឡានក្រុងសម្រាប់កុមារ ប្រាក់ពិន័យពេលសងសៀវភៅបណ្ណាល័យយឺត កញ្ចប់ data ទូរស័ព្ទ ពិន្ទុជាប់ប្រឡង។ សរសេរវាឱ្យបានច្បាស់លាស់ តាមរបៀបដែល program មួយត្រូវការ។ ផ្ដល់ករណីធម្មតាមួយ ករណី boundary (ព្រំដែន) មួយ (ត្រូវនឹងកម្រិតកំណត់ចំៗ) និងករណីចម្លែកមួយ (បាត់ អវិជ្ជមាន ឬមិនធម្មតា)។ នរណាជាអ្នកសម្រេចវិធាននេះ ហើយនរណារងផលប៉ះពាល់ ពេល boundary ខុស?

## R3 · ការពិនិត្យ input

ហេតុអ្វីបានជាប្រព័ន្ធពិនិត្យ input មុននឹងរក្សាទុកវា? ជ្រើសរើស form មួយដែលអ្នកធ្លាប់ប្រើ។ សម្រាប់ field ពីររបស់វា ប្រាប់ value ដែលអនុញ្ញាត ឧទាហរណ៍មិនត្រឹមត្រូវមួយ សារដែលបង្ហាញ (ឬសារដែលគួរបង្ហាញ) និងអ្វីដែលត្រូវតែនៅដដែល ពេល input មិនត្រឹមត្រូវ។

## R4 · របៀបដែលប្រព័ន្ធរក្សាទុកទិន្នន័យ និងប្រវត្តិ

ជ្រើសរើសឧទាហរណ៍ពិតមួយ: របាយការណ៍គណនីធនាគារ (bank statement) កំណត់ត្រារបស់សាលា បញ្ជីការហៅរបស់ទូរស័ព្ទ (call log)។ តើគេរក្សាទុកអ្វីខ្លះ? គេប្រើ ID អ្វីខ្លះ? ពេលកែអ្វីមួយ តើ value ចាស់នៅតែត្រូវបានរក្សាទុកឬទេ? នរណាត្រូវការប្រវត្តិនេះ ហើយហេតុអ្វី?

## R5 · ការរក្សាទិន្នន័យឱ្យមានសុវត្ថិភាព

ស្វែងយល់អំពី backup, audit log និង transaction។ ឧទាហរណ៍: ការផ្ទេរប្រាក់តាមធនាគារមាន update ពីរ (ដកប្រាក់ពីគណនីមួយ ហើយបន្ថែមវាទៅគណនីមួយទៀត) ដែលត្រូវតែជោគជ័យជាមួយគ្នា ឬបរាជ័យជាមួយគ្នា។ តើអ្វីអាចខុសនៅចន្លោះ update ទាំងពីរ? តើអ្នកនឹងពិនិត្យ records មុន និងក្រោយ ដោយរបៀបណា?

## R6 · ការពិនិត្យលទ្ធផលពី AI

យកចម្លើយមួយពី AI ចំពោះសំណួរអំពីការពិត ឬសំណួរបច្ចេកទេស (ឬប្រើឧទាហរណ៍ក្នុង notebook សប្ដាហ៍ទី 7)។ ពិនិត្យវាធៀបនឹងប្រភពដើម។ រាយបញ្ជីអ្វីដែលអ្នកនឹងទទួលយក អ្វីដែលអ្នកនឹងកែ និងអ្វីដែលអ្នកនឹងសួរបន្ថែម ហើយប្រាប់ថាអ្នកបានពិនិត្យចំណុចនីមួយៗដោយរបៀបណា។

## ការប្រើឧបករណ៍ AI សម្រាប់ការស្រាវជ្រាវ

អនុញ្ញាតឱ្យប្រើឧបករណ៍ AI។ បើអ្នកប្រើ សូមបង្ហាញកន្លែងមួយដែលអ្នកបានពិនិត្យ ឬកែវា ហើយប្រាប់ថាដោយរបៀបណា។ អ្វីដែលអ្នកដាក់ស្នើ ត្រូវតែជាការពន្យល់ផ្ទាល់ខ្លួនរបស់អ្នក។ អ្នកអាចទទួលបានពិន្ទុពេញ ដោយមិនប្រើ AI ក៏បាន។
