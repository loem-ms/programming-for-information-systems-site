## កំណត់ត្រាការសម្រេចចិត្ត (decision log)

ការសម្រេចចិត្តមួយ ជួរដេកមួយ នៅក្នុង `README.md` របស់អ្នក។ កំណត់ត្រាការសម្រេចចិត្តរបស់អ្នក ពីសប្ដាហ៍ទី 5–9 មានការសម្រេចចិត្តដែលអាចជ្រើសបាន ជាមួយភស្តុតាងរួចហើយ៖ ចូរជ្រើសរើសបីពីនោះ។

| Setting (file) | តម្លៃរបស់ខ្ញុំ (default) | ជម្រើសផ្សេង | មូលហេតុដែលខ្ញុំជ្រើស | ភស្តុតាង (evidence) (ទិន្នន័យ / សប្ដាហ៍) | អ្នកដែលរងផលប៉ះពាល់ / ផលប៉ះពាល់ទៅវិញទៅមក (trade-off) |
|---|---|---|---|---|---|
| `URGENT_HOURS` (`rules.py`) | 4 (3) | `REJECT_IF_HOURS_LEFT_BELOW` = 2 | អ្នកស្ម័គ្រចិត្តគួរទៅយកឱ្យបានឆាប់ជាងមុន សម្រាប់ការផ្ដល់ជូនដែលជូនដំណឹងយឺត | ការផ្ដល់ជូនដែលនៅសល់ 3 ម៉ោង ឬតិចជាងនេះ៖ លុបចោល 28% ធៀបនឹង 5% (`cancel_rate` សប្ដាហ៍ទី 9) | អ្នកស្ម័គ្រចិត្តធ្វើដំណើរបន្ទាន់ច្រើនជាងមុន។ ប្រសិនបើអ្វីៗទាំងអស់បន្ទាន់ គ្មានអ្វីបន្ទាន់ទេ |

**ខ្សោយ:** "`URGENT_HOURS` = 4 ព្រោះទិន្នន័យបានប្រាប់ដូច្នោះ។" **រឹងមាំ:** ជួរដេកខាងលើ។ ជួរដេកដែលរឹងមាំ បញ្ជាក់តម្លៃជាក់លាក់មួយ ជម្រើសផ្សេងពិតប្រាកដមួយ មូលហេតុដែលភ្ជាប់នឹងមនុស្ស ឬទិន្នន័យ ភស្តុតាង (លេខមួយ តារាងសិទ្ធិ 🔐 របស់អ្នក ឬការស្នើសុំរបស់មនុស្សម្នាក់ និងសប្ដាហ៍ដែលវាមកពី) និងអ្នកណាទទួលបានផល អ្នកណាបាត់បង់។ "វាល្អជាង" មិនមែនជាមូលហេតុទេ ហើយ "ទិន្នន័យបានប្រាប់ដូច្នោះ" ក៏មិនមែនជាភស្តុតាងដែរ។

4. **ការហ្វឹកហាត់តេស្តស្ទង់មើល (canary drill)** (សប្ដាហ៍ទី 10, Lab 2)៖ ប្ដូរតម្លៃថេរ (constant) មួយ មើលវាទៅដល់អេក្រង់ ហើយប្ដូរវាត្រឡប់មកវិញ។ ប្រសិនបើអ្នកបានធ្វើកម្រិតទី 4 ក៏ត្រូវមានតេស្តស្ទង់មើលនៃ `screen.py` ដែរ។

កំណត់ត្រាល្អមួយ ក៏មាន **ការពិនិត្យថាលេខសមហេតុផល (sanity check)** ពីសប្ដាហ៍ទី 10 ដែរ (status ទាំងអស់បូកគ្នាស្មើនឹងការផ្ដល់ជូន 404 អត្រានីមួយៗស្ថិតនៅចន្លោះ 0 និង 100 % ហើយក្រុមទទេផ្ដល់ 0.0)។

## កម្រិតទី 4 · អេក្រង់មួយ

ចូរផ្ដល់ឱ្យ AI នូវលក្ខខណ្ឌកំណត់ (contract) មួយ មិនមែនគ្រាន់តែជាបំណងប្រាថ្នាទេ (ចម្លងអត្ថបទជាភាសាអង់គ្លេសខាងក្រោម)៖

> Write a Python file `screen.py` with one function, `make_page(records)`. It returns an HTML page as one string (a `str`). Show one row per open offer (new, approved or picked_up), most urgent first. Import `urgency` from `rules.py` and `most_urgent_first` from `report.py`, and use them. Put all imports at the top of the file. Do not write any of their numbers again. Use only the Python standard library. Never show the contact field.

ចូរអានកូដ មុនពេលអ្នក run វា៖ អ្នកបានសរសេរ loop ដដែល និង `html.escape` ដដែលនេះ នៅសប្ដាហ៍ទី 8។ បន្ទាប់មក ចូរធ្វើ **តេស្តស្ទង់មើល (canary test)**៖ ប្ដូរ `URGENT_HOURS` ក្នុង `rules.py` (ទៅ 10 ប្រសិនបើវាតិចជាង 5 ឬទៅ 1 ប្រសិនបើវាស្មើ 5 ឬច្រើនជាងនេះ) run `bridge.show("screen")` ម្ដងទៀត ហើយមើលថាទំព័រប្រែប្រួលឬទេ។ ប្រសិនបើវាមិនប្រែប្រួលទេ មានន័យថា AI បានចម្លងវិធាន ជំនួសឱ្យការ import វា៖ ចូរសួរវាម្ដងទៀត។ ប្ដូរតម្លៃត្រឡប់ទៅដូចដើមវិញ ហើយសរសេរអ្វីដែលអ្នករកឃើញ ក្នុងកំណត់ត្រាការផ្ទៀងផ្ទាត់របស់អ្នក។
