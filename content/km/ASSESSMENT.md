# ការវាយតម្លៃ

វគ្គសិក្សានេះវាយតម្លៃអ្វីដែលអ្នក **យល់ បង្កើត សាកល្បង (test) និងពន្យល់បាន**។ ភាគរយពិន្ទុខាងក្រោម គឺជា **ផែនការដែលបានស្នើឡើង**។ គ្រូនឹងបញ្ជាក់វាជាមួយសាកលវិទ្យាល័យ មុនពេលការវាយតម្លៃចាប់ផ្ដើម។ ថ្ងៃផុតកំណត់តាមប្រតិទិន និងឈ្មោះ file នឹងប្រកាសនៅក្នុងថ្នាក់។

| ផ្នែក | ភាគរយ | អ្វីដែលរាប់ពិន្ទុ |
|---|---:|---|
| ការចូលរួម | 10% | ចូលរួមសកម្មភាពក្នុងថ្នាក់ និងបំពេញ form ការឆ្លុះបញ្ចាំង (reflection) ប្រចាំសប្ដាហ៍ |
| កិច្ចការស្រាវជ្រាវចំនួន 6 | 30% | 5% ក្នុងមួយកិច្ចការ: អ្វីដែលអ្នកបានអាន ឬបានរកឃើញ ឧទាហរណ៍ជាក់ស្ដែងមួយ ការពិនិត្យមួយ និងការវែកញែករបស់អ្នកផ្ទាល់ |
| Midterm ធ្វើម្នាក់ឯង (សប្ដាហ៍ទី 4) | 30% | អាន សរសេរ និង test code; វាយតម្លៃ code ដែល AI សរសេរ; ពន្យល់ការសម្រេចចិត្តមួយ |
| Final project (សប្ដាហ៍ទី 9–10) | 30% | ប្រព័ន្ធរបស់អ្នកដែលដំណើរការបាន ការសម្រេចចិត្តរបស់អ្នក និងភស្តុតាង (evidence) របស់វា តេស្តរបស់អ្នក ការផ្ទៀងផ្ទាត់ និងថ្ងៃបង្ហាញប្រព័ន្ធ (Demo day) |
| **សរុប** | **100%** | |

## ការចូលរួម (10%)

ចូលរួមសកម្មភាពក្នុងវគ្គទី 1–3៖ ការទាយមើល ការងារជាគូ ការពិភាក្សា "ល្អ ឬមានហានិភ័យ?" និងការចាប់ផ្ដើមថ្នាក់។ ក្រោយរៀងរាល់សប្ដាហ៍ សូមបំពេញ [form ការឆ្លុះបញ្ចាំងប្រចាំសប្ដាហ៍](COURSE_LINKS.md)។ ប្រសិនបើខ្វះ form មួយ គ្រូនឹងសួរតាមដាន។ វាមិនរាប់ជាអវត្តមានដោយស្វ័យប្រវត្តិទេ។

## កិច្ចការស្រាវជ្រាវ (30%)

កិច្ចការខ្លីៗ 6 ដែលមួយៗមាន 5%។ R1 និង R2 ភ្ជាប់គំនិតរបស់សប្ដាហ៍មួយ ទៅនឹងប្រព័ន្ធពិតមួយ។ R3–R6 នីមួយៗបង្រៀនអ្នកអំពីគោលគំនិតមួយនៃការសរសេរកម្មវិធី (programming concept) តាមជំហានប្រាំ៖ អាន និងរៀបចំគំនិត · សួរ AI អំពីចំណុចដែលនៅមិនទាន់ច្បាស់ · ប្រៀបធៀប និងពិនិត្យ · មតិរបស់អ្នក · ប្រភព និងភាពស្មោះត្រង់។ សូមមើល [កិច្ចការស្រាវជ្រាវ](RESEARCH.md) សម្រាប់ប្រធានបទ ជំហាន និងកាលវិភាគ។

**R3–R6**

| លក្ខណៈវិនិច្ឆ័យ | ពិន្ទុ |
|---|---:|
| **អាន និងរៀបចំគំនិត:** សេចក្ដីសង្ខេបជាពាក្យរបស់អ្នកផ្ទាល់ (5–8 ប្រយោគ: វាជាអ្វី ហេតុអ្វីបានជាត្រូវការវា វាដំណើរការយ៉ាងដូចម្ដេច និងកំហុសមួយដែលគេជួបញឹកញាប់) និងឧទាហរណ៍តូចមួយដែលអ្នកបាន run ព្រមទាំងលទ្ធផល (output) របស់វា | 1 |
| **សួរ AI:** បន្ទាត់សំខាន់ៗ 6–10 បន្ទាត់នៃការសន្ទនា រួមទាំងសំណួរបន្ត (follow-up question) ទាំងពីររបស់អ្នក (ឧទាហរណ៍ពីជីវិតប្រចាំថ្ងៃនៅកម្ពុជា និង "តើមានអ្វីអាចនឹងខុសឆ្គង?")។ មិនអាចប្រើ AI បាន: ធ្វើដូចគ្នាជាមួយមិត្តរួមថ្នាក់ ឬគ្រូ ឬឆ្លើយសំណួររបស់អ្នកដោយប្រើជំពូកសៀវភៅទីពីរ | 1 |
| **ប្រៀបធៀប និងពិនិត្យ:** កន្លែងមួយដែល (1) សៀវភៅ និង AI និយាយដូចគ្នាតែប្រើពាក្យខុសគ្នា (2) សៀវភៅ និង AI និយាយខុសគ្នា ឬ (3) AI ឆ្លើយមិនច្បាស់ ឬឆ្លើយខុស; ការអះអាង (claim) មួយដែលអ្នកបានសាកល្បង ដោយ run ឧទាហរណ៍តូចមួយ | 1 |
| **មតិរបស់អ្នក:** ជំហរច្បាស់លាស់មួយ ចំពោះសំណួរសម្រាប់ជជែកពិភាក្សា (debate question) ក្នុង 150–250 ពាក្យ ដោយមានមូលហេតុពីករណីសិក្សារបស់វគ្គសិក្សា | 1 |
| **ប្រភព និងភាពស្មោះត្រង់:** បានប្រាប់ឈ្មោះផ្នែក និងជំពូកដែលអ្នកបានអាន ព្រមទាំងឧបករណ៍ AI ដែលអ្នកបានប្រើ; ប្រើតែឧទាហរណ៍ប្រឌិត គ្មានទិន្នន័យផ្ទាល់ខ្លួនពិតៗ | 1 |
| **សរុប** | **5** |

សម្រាប់ R1 និង R2 អ្នកអាចប្រើឧបករណ៍ AI បាន ប៉ុន្តែមិនចាំបាច់ទេ។ ប្រសិនបើអ្នកប្រើវា សូមពិនិត្យការអះអាងយ៉ាងហោចណាស់មួយ ដោយខ្លួនឯង ហើយប្រាប់ថាអ្នកបានពិនិត្យដោយរបៀបណា។ និស្សិតដែលមិនប្រើ AI ក៏អាចទទួលបានពិន្ទុពេញដូចគ្នា។ សម្រាប់ R3–R6 អ្នកអានជាមុនសិន។ ការសន្ទនាជាមួយ AI មកក្រោយការអាន ហើយវាជាផ្នែកមួយនៃកិច្ចការ។ ការប្រៀបធៀប និងពិនិត្យអ្វីដែល AI និយាយ ក៏ជាផ្នែកមួយនៃពិន្ទុដែរ។ សេចក្ដីសង្ខេប និងមតិរបស់អ្នក ត្រូវតែជាពាក្យរបស់អ្នកផ្ទាល់។

## Midterm (30%)

បន្ទាប់ពីការចូលរួមប្រចាំសប្ដាហ៍ និងកិច្ចការស្រាវជ្រាវ midterm គឺជាផ្នែកដំបូង ដែលអ្នកធ្វើទាំងស្រុងដោយខ្លួនឯង។

**ពេលណា:** សប្ដាហ៍ទី 4 វគ្គទី 3 (**60 នាទី** ប្រឡងម្នាក់ឯង + **30 នាទី** រៀបចំ ដាក់ស្នើ និងពិភាក្សាចម្លើយ)។ **ការចូលប្រឡង:** [ទំព័រ Midterm](MIDTERM.md) (លេខកូដ PIN ប្រកាសក្នុងថ្នាក់)។ **ធ្វើម្នាក់ឯង។** អនុញ្ញាត៖ កំណត់ចំណាំរបស់អ្នក notebook ប្រចាំសប្ដាហ៍ និង notebook Python Basics។ **មិនអនុញ្ញាត៖** ឧបករណ៍ AI ការផ្ញើសារ ឬការចែករំលែក code។

ក្រោយពេលអ្នកដាក់ស្នើ មាន **ការពិនិត្យផ្ទាល់មាត់ខ្លី 2–3 នាទី**៖ គ្រូសួរអំពី **បន្ទាត់កូដសំខាន់របស់ខ្ញុំ (My key line)** និងបន្ទាត់ ឬ test មួយទៀតក្នុង notebook របស់អ្នក។ ប្រសិនបើអ្នកមិនអាចពន្យល់ code ផ្ទាល់ខ្លួនរបស់អ្នកបានទេ ពិន្ទុនៃផ្នែកនោះ អាចត្រូវកាត់បន្ថយ។

## Final project (30%)

ផ្នែកចុងក្រោយ ផ្គុំវគ្គសិក្សាទាំងមូលបញ្ចូលគ្នា នៅសប្ដាហ៍ទី 9–10៖ folder `my_foodbridge/` ផ្ទាល់ខ្លួនរបស់អ្នក ដែលបានបញ្ចប់ ផ្ទៀងផ្ទាត់ និងបង្ហាញរួច។ មើល [មគ្គុទ្ទេសក៍ Final project](FINAL_PROJECT.md) សម្រាប់កម្រិតទាំង 4 កំណត់ត្រាទាំងពីរ និងអ្វីដែលត្រូវដាក់ស្នើ។

## យុត្តិធម៌ និងភាពស្មោះត្រង់
